# Sahi Management System (SahiApp)

A desktop management application developed in **C#** and **.NET (WinForms)** designed to streamline volunteer operations, inventory tracking, and food basket distribution logistics for the **SAHI** community organization.

---

## Key Features

* **Operations & Distribution Management:** Centralized interface (`Form1`) for organizing volunteer schedules, recipient records, and distribution routes.
* **Structured Domain Modeling:** Dedicated data models (`Models.cs`) representing operational entities and logistics workflows.
* **Data Persistence & Serialization:** Custom serialization engine (`Serializer.cs`) for saving and loading application state reliably across sessions.

---

## Tech Stack

* **Language:** C# (.NET)
* **GUI Framework:** Windows Forms (WinForms)
* **Version Control:** Git & GitHub

---

## Project Structure

* `SahiApp/Form1.cs` – Main graphical user interface and event-driven interaction logic.
* `SahiApp/Models.cs` – Core business entities and data structures.
* `SahiApp/Serializer.cs` – State persistence and file serialization logic.
* `SahiApp/Program.cs` – Application entry point.
